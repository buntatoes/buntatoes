<details>
<summary>Python — 1991</summary>

Guido van Rossum, CWI. Successor to ABC; it spread on readability, then science and the web. Still the reference is CPython. Used for data, automation, backends, AI tooling. Holdfast is Python.

</details>

<details>
<summary>JavaScript — 1995</summary>

Brendan Eich, Netscape. Standardized as ECMAScript. Node.js (2009) took it onto servers. The language of the web client, and a large share of backends. AdAegis is JavaScript.

</details>

<details>
<summary>TypeScript — 2012</summary>

Anders Hejlsberg, Microsoft. A typed superset of JavaScript. Angular and VS Code helped it become the default for many new web apps.

</details>

<details>
<summary>Java — 1995</summary>

James Gosling et al., Sun. Portable bytecode, then the enterprise default of the 2000s, then Android. Still large backends and JVM platforms.

</details>

<details>
<summary>C — 1972</summary>

Dennis Ritchie, Bell Labs. Written so Unix could leave assembly. Still kernels, embedded, and anything that talks to the metal.

</details>

<details>
<summary>C++ — 1985</summary>

Bjarne Stroustrup, Bell Labs. C with abstraction, later templates and RAII. Games, browsers, finance, native toolkits.

</details>

<details>
<summary>C# — 2000</summary>

Anders Hejlsberg, Microsoft. Shipped with .NET; Unity and open-source .NET carried it off Windows. Backends, desktop, games.

</details>

<details>
<summary>Go — 2009</summary>

Griesemer, Pike, Thompson at Google. Fast compiles, goroutines, a small language. Docker and Kubernetes are written in it.

</details>

<details>
<summary>PHP — 1995</summary>

Rasmus Lerdorf. Cheap hosting and MySQL made it the default way to put a database on the web. WordPress, Laravel, Wikipedia.

</details>

<details>
<summary>Ruby — 1995</summary>

Yukihiro Matsumoto. Meant to feel natural to write. Rails (2004) made it the web stack of the late 2000s; GitHub began as a Rails app. Still Rails, scripting, and tools that never left.

</details>

<details>
<summary>Rust — 2010</summary>

Graydon Hoare, Mozilla; 1.0 in 2015. Memory safety without a garbage collector. Systems software, CLIs, growing kernel use. RingZero is a local Linux scanner in Rust.

</details>

<details>
<summary>Kotlin — 2011</summary>

JetBrains. Google made it the preferred Android language. Java interop let teams move incrementally.

</details>

<details>
<summary>Elixir — 2011</summary>

José Valim. Ruby-like syntax on the Erlang VM; actors and supervision from BEAM. Phoenix for long-lived connections. ChorusDraft is Elixir.

</details>

<details>
<summary>SQL — 1974</summary>

Chamberlin and Boyce at IBM, from Codd’s relational model. ANSI 1986. Still how most business data is queried.

</details>

<details>
<summary>Swift — 2014</summary>

Chris Lattner et al., Apple. Successor to Objective-C on Apple platforms. iOS and macOS work lives here.

</details>

<p align="center"><em>on this desk</em></p>

<details>
<summary><a href="https://github.com/buntatoes/holdfast">Holdfast</a> — Python · Linux</summary>

Agents propose open, exec, and connect. Holdfast intercepts the call. Policy or a person allows it. Missing daemon, unknown op, timeout: deny. Prompts are not a security boundary. Linux only. No phone-home.

</details>

<details>
<summary><a href="https://github.com/buntatoes/chorusdraft">ChorusDraft</a> — Elixir</summary>

Human-reviewed drafts for Bluesky and Mastodon. Models write. You ship. Voice is dry wit; serious topics stay sincere. It does not auto-like, favourite, boost, or repost.

</details>

<details>
<summary><a href="https://github.com/buntatoes/adaegis">AdAegis</a> — JavaScript</summary>

A small unpacked extension for desktop Chrome and Chromium 120+. Bundled rules for common ad-tech domains. No account, no telemetry, no remote filter list. Lists stay on disk.

</details>

<details>
<summary>SpecPulse — Python</summary>

Living tracker for 3GPP / 6G specifications, change requests, and working-group movement. Each snapshot keeps provenance. Early seed; it stays on this machine.

</details>

<details>
<summary>RingZero — Rust · Linux</summary>

Experimental on-demand file scanner. Loopback only. Findings are a signal for review, not a verdict. It does not upload files or telemetry.

</details>
